# Mochi Website

Official marketing website, documentation viewer, benchmark explorer, and showcase for **[Mochi](https://github.com/xanstomper/mochi)** — the minimal, fast, autonomous AI coding agent for the terminal.

Live at: **[xanstomper.github.io/mochi/](https://xanstomper.github.io/mochi/)**

## Tech Stack
- React 18
- Vite 5
- JetBrains Mono, Inter, Space Grotesk typography
- Interactive SVG & canvas visualizers

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Output compiles into `/docs` for GitHub Pages hosting.
